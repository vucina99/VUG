# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

VUG — a single-page bilingual (Serbian/English) marketing site for a digital agency. Vanilla PHP + CSS + JS, no build step, no framework, no package manager. It runs under WAMP/Apache at `C:\wamp64\www\VUG digital` and is served directly (`DirectoryIndex index.php`). Production host is `vugagency.com` (set as `$SITE_URL` at the top of `index.php`; drives canonical, hreflang, OG and JSON-LD).

## Running & testing

There is no build, lint, or test tooling. To view changes, open the site through the local Apache server (WAMP), e.g. `http://localhost/VUG%20digital/`, and reload — PHP is interpreted at request time. Do **not** open `index.php` via `file://`; the PHP won't execute.

- Language switch: English is served at the clean URL `/en` (rewritten to `index.php?lang=en` in root `.htaccess`); Serbian stays at `/`. Anything else falls back to `sr`. `index.php` 301-redirects legacy `?lang=…` and trailing-slash `/en/` to the canonical form. URLs are base-path aware (`$base_path`/`$href_*`), so they work both in the local subfolder (`/VUG digital/en`) and at the production root (`/en`).
- The contact form (`php/contact.php`) uses PHP `mail()`, which typically does nothing on local WAMP. To exercise the form end-to-end, test on a real mail-capable host; locally, verify client-side validation (`js/main.js`) and the JSON response shape instead.

## Architecture

**Everything renders from `index.php`.** It is one long template: it selects the language array, then emits nav → hero → services → about → process → CTA → testimonials → FAQ → references → contact → footer. Section content (service cards, process steps, testimonials, FAQ, partner logos) is generated by looping over PHP arrays defined inline in `index.php` — to add/remove a card, edit the array literal in the relevant section, not separate data files.

**All user-facing text lives in `lang/sr.php` and `lang/en.php`.** Each returns a flat `key => string` PHP array, and the two files must stay key-for-key identical — only the values differ. Never hardcode display copy in `index.php`; add a key to both language files and reference `$t['key']`. Some strings contain HTML and are echoed unescaped (`<?= $t[...] ?>`), so they are trusted content by design.

**Three layers, cleanly separated:**
- `index.php` — structure + PHP loops + i18n lookup. Helper `split_words()` wraps each word in `<span class="word">` for the hero title reveal animation.
- `css/critical.css` + `css/style.css` — jedan stylesheet razdvojen u dva fajla (above-the-fold / ostalo; vidi "Performance & assets"). All theming flows from CSS custom properties in `:root`, koji su u **`critical.css`** (dark deep-purple palette `--bg`/`--violet`/`--mint` etc., fonts `--ff`/`--ff-mono`, `--container`, `--nav-h`). Change design tokens there, not scattered values.
- `js/main.js` — one IIFE, no dependencies. Progressive enhancement: scroll-nav state, **traka napretka skrolovanja**, mobile menu, IntersectionObserver reveals, animated counters (`.counter` with `data-target`/`data-suffix`), smooth scroll, custom cursor + magnetic buttons + hero glow (desktop, non-reduced-motion only), testimonial marquee, and the contact-form AJAX submit. It reads `isCoarse`/`reduced` flags up top and gates motion features on them.

**Traka napretka skrolovanja** (`.scroll-progress` / `#scrollProgress`) stoji **na svakoj stranici** (2026-08-05; ranije samo na stranici projekta kao `.pd-progress`): markup je u `partials/header.php` odmah posle sprite-a, pravilo u **`css/critical.css`** kod `.nav` bloka (a ne u `style.css`, jer je above-the-fold — non-blocking stylesheet bi je „uskočio“ posle prvog iscrtavanja), a logika u `js/main.js` (`scaleX` po `scrollY / (scrollHeight - innerHeight)`). Osvežava se i na `load`/`hashchange`, jer kad se na stranicu dođe sa sidrom u URL-u (`/#contact`) skok se odigra pre prvog merenja i traka bi ostala prazna do prvog skrola. Boja je `--pa1`→`--pa2` kad ih stranica projekta postavi, inače cijan→mint.

**Kontakt sekcija (forma + info kartice) je u `partials/contact.php`** — JEDAN izvor markupa. Uključuju je i `index.php` (broj sekcije `07`) i `landing.php` (poslednja sekcija). **Ne kopirati formu u novu stranicu** — `require __DIR__ . '/partials/contact.php';` uz prethodno postavljene `$t`, `$lang`, `$base`, `$phone_intl` i opcioni `$contact_num`. Javni `$RECAPTCHA_SITE_KEY` živi u tom partialu (ne više u `index.php`), a `action` forme je base-aware (`$base . '/php/contact.php'`), pa radi i u podfolderu i u rootu.

**Contact flow:** `js/main.js` validates fields, fetches a **reCAPTCHA v3** token (`grecaptcha.execute`, action `contact`) and appends it as `recaptcha_token`, then POSTs `FormData` to `php/contact.php`, expecting `{ok, message, errors?}` JSON. `contact.php` re-validates server-side (never trust the client), checks a `website` honeypot field, verifies the reCAPTCHA token with Google (score ≥ `$RECAPTCHA_MIN_SCORE`, matching action), guards against header injection, builds a multipart HTML+plain email, and sends via `mail()`. Error messages are keyed and pulled from the same `lang/*.php` files (`form_err_*`, `form_success`, `form_error`) so JS and PHP share one source of copy — the JSON block `#formMessages` in `partials/contact.php` bridges them to the client. reCAPTCHA is keyed by `$RECAPTCHA_SITE_KEY` (public, in `partials/contact.php`) + `$RECAPTCHA_SECRET` (in `contact.php`); leaving either blank disables the check so local dev still works.

## Lokalne landing stranice (`landing.php`, prošireno 2026-09-22)

Jedan kontroler opslužuje **8 URL-ova**: dve usluge (`svc=web` / `svc=social`) × dva grada (`loc=pancevo` / `loc=beograd`) × dva jezika. Rute su u `.htaccess` (`/izrada-web-sajta-<grad>`, `/vodjenje-drustvenih-mreza-<grad>`, EN varijante pod `/en/` sa **istim srpskim slug-om**).

- **Sadržaj je u dva sloja.** Hero + sekcija `01` („Zašto VUG") žive u nizovima `$CITY`/`$COPY` **unutar `landing.php`**. Sve ispod toga (usluge, proces, delatnosti, cena, FAQ) je u **`php/landing-content.php`**, koji vraća `['ui' => [svc][lang], 'city' => [svc][loc][lang]]`. Ovo je strukturiran sadržaj, kao `php/projects.php` i `legal.php` — **ne ide u `lang/*.php`**. Ključevi u `sr` i `en` moraju biti identični.
- **Sekcije se renderuju po prisustvu ključa**, ne po `if`-u za grad: `serv`, `proc`, `ind`, `price`, `faq`. **Obe usluge (`web` i `social`) imaju pun set** (`02` usluge → `03` proces → `04` delatnosti → `05` cena → `06` FAQ → `07` kontakt), za oba grada i oba jezika — ukupno 8 stranica sa istom strukturom i 4 različita teksta. **Dodavanje ključa u `landing-content.php` samo pojavi sekciju** — prikaz se ne dira. Numeracija (`$num()`) broji samo renderovane sekcije, pa nema rupa; brojač stoji IZNAD `if (!empty($X))` jer kontakt sekcija ide i kad grad nema prošireni sadržaj.
- **Poslednja sekcija je KONTAKT FORMA** iz `partials/contact.php` (isti markup kao na početnoj). Zato landing stranice više ne vode „Kontakt" u meniju na početnu — `$contact_href`/`$cta_href` su `'#contact'`, lokalno sidro.
- **`area_served` u `landing-content.php` nije prikaz** — puni samo `areaServed` u JSON-LD grafu.
- **Chip-ovi delatnosti (`.lp-chips li`) imaju isti hover kao krug sa brojem**: akcentna pozadina, taman tekst, blago podizanje i glow (2026-09-22).
- **Hero slika je LCP element** — nosi `fetchpriority="high"` i `decoding="async"`, i **ne sme `loading="lazy"`**.
- **Tekst po gradu MORA biti jedinstven.** Google lokalne landing stranice sa istim tekstom tretira kao doorway stranice. **Dizajn i struktura su namerno identični za oba grada — tekst nije.** Deli se samo okvir (labele u `ui`); naslovi, pasusi, opisi usluga, delatnosti i FAQ odgovori pišu se posebno za Pančevo i za Beograd. Kad se neka izmena prenosi sa jedne stranice na drugu, **prepiši je drugim rečima**, ne copy-paste.
  - Isto važi i **između usluga u istom gradu** (`izrada-web-sajta-pancevo` vs `vodjenje-drustvenih-mreza-pancevo`) — tu se najlakše provuku iste rečenice u `ind_lead` i `price_note`.
  - Provera (posle svake veće izmene teksta): uporedi rečenice iz `<main>` **svih 6 parova** landing stranica po jeziku — **sadržajnih poklapanja mora biti 0**; smeju ostati samo naslov FAQ pitanja i deljena kontakt sekcija. Jednom je posle prenosa izmena na Beograd broj skočio na 10 identičnih rečenica i moralo je da se prepisuje.
- **Ritam pozadina prati početnu**: `01` cream → `02` tamno → `03` svetlo → `04` tamno → `05` cream → `06` tamno (FAQ) → `07` svetlo (kontakt). **Poslednja sekcija je uvek svetla** — futer je već taman (isto pravilo kao na stranici projekta).
- **Brojevi koraka (`.lp-step-n`) u sekcijama `03` i `05` namerno kopiraju `.step-dot` sa početne**: krug sa bg swap-om, `scale(1.08)`, glow-om i isprekidanim prstenom na hover. Idu `1,2,3` — bez vodeće nule, jer ih ima najviše pet.
- **Broj je VERTIKALNO CENTRIRAN prema naslovu + opisu** (`align-items:center` na `.lp-step`). Zato krug stoji u omotaču `.lp-step-rail` koji se rasteže preko cele visine reda: linija se crta na šini (`top:0; bottom:-34px`, tj. preko razmaka do sledećeg kruga), a krug je neproziran i maskira deo linije iza sebe. Prvom koraku linija počinje na `top:50%`, poslednjem se završava na `bottom:50%` — tako nema viška iznad prvog ni ispod zadnjeg broja. `bottom:-34px` MORA da prati `padding-bottom` na `.lp-step`.
- **`.lp-note` („Kako dolazite do cene") NE sme `position:sticky`** — izričit zahtev: kartica stoji na mestu dok se skroluje.
- **FAQ koristi postojeće `.faq-card*` komponente** iz `style.css` (imaju i tamnu i svetlu varijantu), a isti niz pitanja puni i `FAQPage` markup — sadržaj iz JSON-LD-a se **mora** videti i u HTML-u.
- **JSON-LD se nadograđuje, ne prepisuje**: posle `$json_ld = [...]` petlja traži čvorove **po `@type`** (ne po indeksu) i dodaje `mainEntity` (FAQPage) na `WebPage`, te `areaServed` (grad + okolna mesta), `hasOfferCatalog` i `availableChannel` na `Service`. Graf je `Service → WebSite → WebPage+FAQPage → BreadcrumbList`; `provider` nosi pun lokalni profil (`geo`, `hasMap`, `openingHoursSpecification`, `sameAs`, `priceRange`) pod **istim `@id`** kao na početnoj, pa Google spaja entitet. **Ne dodavati `mainEntity` na `WebPage`** — FAQ petlja ga prepisuje.
- **hreflang: srpski je primarni jezik, `x-default` MORA da vodi na srpsku verziju.** Skup je `sr`, `sr-RS`, `sr-BA`, `sr-ME`, `sr-HR`, `en`, `x-default` — identičan na obe jezičke verzije svake stranice (hreflang je recipročan) i isti u `sitemap.xml`. Regionalne varijante postoje da srpska verzija ide i korisnicima iz BiH, Crne Gore i Hrvatske; sa samo `sr-RS` svi ostali padnu na `x-default`. Do 2026-09-23 je `x-default` na početnoj gađao `/en`, pa je Google svima van Srbije nudio englesku verziju.
- **Automatsko preusmeravanje po IP adresi NE raditi.** Googlebot puzi uglavnom sa američkih IP-jeva, pa bi video samo englesku verziju — srpske stranice bi ostale neindeksirane. Jezik se bira hreflang-om, a korisniku se najviše sme ponuditi nenametljiv baner sa linkom.
- **Email adresa ne sme u JSON-LD** (`'email'` u `Organization`): unutar `<script>` bloka HTML entiteti se ne dekodiraju, pa bi adresa stajala kao čist tekst u izvoru i prekršila pravilo iz „Conventions".
- **Title se meri U PIKSELIMA — Arial 20px, granica 600px.** Pravilo „60 znakova" je nepouzdano: prefiks „Vođenje društvenih mreža <Grad> - " sam troši ~340px, pa u naslov staju DVE platforme, ne tri. Meriti stvarnim Arial advance-width tabelama (procena po grubim prosecima je jednom pokazala 559px za naslov koji je zapravo 754px i sekao se). **Description se meri po BROJU ZNAKOVA**: ≤155 za desktop, cilj ≤130 da poziv na akciju preživi i na mobilnom.
- **Stanje pravila, provereno 2026-09-23** (istraženo na Google Search Central i SEO izvorima):
  - **FAQ rich results su ukinuti 7. maja 2026.** `FAQPage` je i dalje validan Schema.org tip i ne smeta, ali **više ne pravi proširen prikaz u rezultatima**. Ne trošiti vreme na optimizaciju za taj rich result; markup ostaje jer pomaže AI pretraživačima da izvuku odgovore.
  - **Core Web Vitals pragovi**: LCP < 2,5s, INP < 200ms, CLS < 0,1 (75. percentil stvarnih poseta). INP je zamenio FID; nema novih metrika. Zato hero slika nosi `fetchpriority="high"`, sve slike imaju `width`/`height` (CLS), `main.js` ide sa `defer`, a critical CSS je inline.
  - **Mobile-first indeksiranje**: mobilna navigacija MORA biti u HTML-u (`.nav-mobile` u `partials/header.php`), ne ubačena JavaScript-om — inače Googlebot Smartphone vidi praznu strukturu.
  - **`<lastmod>` je signal svežine** za Google, Bing i AI botove. **Menjati ga samo za stranice koje su se stvarno promenile** — masovno postavljanje svih na današnji datum pri svakom deploy-u obezvređuje signal.
  - **AI crawleri su namerno dozvoljeni** (`User-agent: *` u `robots.txt` pokriva GPTBot, ClaudeBot, PerplexityBot, Google-Extended). Ne dodavati im Disallow — vidljivost u AI odgovorima se sve više oslanja na potpunost strukturiranih podataka.
  - **Podaci u `Organization` grafu moraju da se poklapaju sa Google poslovnim profilom** (naziv, adresa, telefon, radno vreme). Neslaganje pravi konflikt entiteta i šteti lokalnom rangiranju.
- **SEO provera pred izmenu/deploy**: title ≤600px i ≥30 znakova, description ≤960px i ≥90 znakova, tačno jedan `<h1>`, 7 `hreflang` veza (recipročnih), canonical, svaki `<img>` sa `alt`, hero slika sa `fetchpriority="high"`, FAQ markup = vidljiva pitanja, bez duplih title/description, bez emaila kao čistog teksta. Posle izmene sadržaja osveži `<lastmod>` u `sitemap.xml` (10 URL-ova; `/projekti` NIJE unutra).
- **CSS proširenih sekcija (`.lp-card`, `.lp-step`, `.lp-chips`, `.lp-split`, `.lp-note`, `.lp-rel`) je u `$extra_head`**, ne u `style.css` — koristi se samo ovde, pa ostale stranice ne plaćaju te kilobajte. Svaka komponenta ima svetlu varijantu (`--mint`/`--cyan` → `--violet`/`--blue`). `.lp-card`/`.lp-step` su deca `.stagger`-a, pa im `transition` **mora** da sadrži `transform` i `opacity`.
- **Proces (`proc`) ima ČETIRI koraka** — razgovor → plan i struktura → izrada i testiranje → lansiranje i podrška. Zaseban korak „Dizajn" je uklonjen 2026-09-22, a dizajn je ušao u opis koraka „Plan i struktura". Ako se broj koraka menja, **mora i uvodna rečenica** (`proc_lead` počinje sa „Četiri koraka" / „Four steps") — inače tekst laže ono što se vidi.
- Probano i **odbačeno** (ne vraćati): traka „Na ovoj stranici" sa sidrima ka sekcijama (`.lp-toc`), blok „Radimo za klijente iz … i okoline" sa spiskom naselja (`.lp-areas`), zasebna sekcija „Kontakt i lokacija" sa NAP karticama (`.lp-nap`) — zamenjena pravom formom, dugme „Kontaktirajte nas" ispod teksta u sekciji `01`, i blok „Povezane stranice" (`.lp-rel`) sa internim linkovima na dnu FAQ sekcije.
- Posle izmene sadržaja: osveži `<lastmod>` za te URL-ove u `sitemap.xml`.

## Performance & assets (post 2026-07-22 optimizacija)

- **CSS je razdvojen na dva fajla, bez duplikata** (post 2026-07-28, zbog "render blocking resources" + FCP/LCP):
  - `css/critical.css` — above-the-fold: `@font-face`, `:root` tokeni, reset/base, mesh/grain, cursor, `.container`, `.btn*`, `.nav*`, `.hero*` i njihovi breakpoint-i. **Ne učitava se kao `<link>`** — `partials/head.php` ga čita (`file_get_contents`), lagano minifikuje i ubacuje INLINE u `<head>`, pa prvi ekran nema ni jedan blokirajući zahtev. Putanje `../fonts/` se pri inline-ovanju prepisuju u `$base . '/fonts/'` (u inline `<style>` relativne putanje idu od URL-a stranice, ne od `css/` foldera — i tako se poklapaju sa `<link rel="preload">`).
  - `css/style.css` — sve od `#services` nadole. Učitava se **non-blocking**: `media="print"` + `onload="this.media='all'"`, uz `<noscript>` fallback. Stoji PRE `$extra_head` da stranični `<style>` blokovi i dalje pobeđuju u kaskadi.
  - Pravilo živi u **tačno jednom** fajlu. Menjaš nav/hero/dugmad/tokene → `critical.css`. Menjaš sekcije → `style.css`. Ne duplirati `@font-face`/`:root`.
- **Fontovi su self-hosted** u `/fonts/` (variable woff2). `@font-face` je na vrhu `css/critical.css` (putanje `../fonts/`), sa `font-display:swap` i metric-adjusted fallback-om (`Jakarta Fallback`/`Grotesk Fallback`). Nema Google Fonts `<link>`/preconnect. Dva kritična Jakarta faca se preload-uju u `<head>`. Ne vraćati eksterni Google Fonts.
- **Google Analytics se učitava lenjo** — `partials/head.php` odmah postavi `dataLayer`/`gtag()` queue, a `gtag.js` ubaci posle `load` eventa (+1s) ili na prvu interakciju. Ne vraćati `<script async src="…gtag/js">` na vrh `<head>` (troši propusni opseg na putu do prvog iscrtavanja).
- **Ikonice su inline SVG**, ne Bootstrap Icons. `php/icons.php` daje `vug_icon($name)` (+ `vug_icon_sprite()` koji se emituje jednom posle `<body>`). CSS klasa `.vi`. Koristi `vug_icon('arrow-right')`.
- **reCAPTCHA se učitava lenjo** (na prvu interakciju sa formom) iz `js/main.js` — ne na svakom učitavanju.
- Partner logoi imaju `.webp` verzije servirane preko `<picture>` (PNG fallback).
- `404.php` (ErrorDocument, pravi 404) i `legal.php` (privatnost/uslovi/kolačići; čisti URL-ovi u `.htaccess`; trenutno `noindex` NACRT do pravne provere).
- `ads.txt` u rootu — namerno bez `DIRECT`/`RESELLER` zapisa (VUG ne prodaje oglasni prostor); prazna lista zapisa po IAB spec znači "nijedan prodavac nije autorizovan". Postoji da SEO/ad provere ne prijavljuju fajl kao nedostajući.

## Conventions

- **Početna strana je referenca za copy.** Nova kopija (portfolio, podstranice) mora da govori istim jezikom kao `services_*`/`about_*`/`process_*` na početnoj: isti **nazivi usluga** („Izrada sajtova i web aplikacija“ → „Sajtovi i web aplikacije“, „Mobilne aplikacije“, „Brending i grafički dizajn“, „Vođenje društvenih mreža“, „Marketing i oglašavanje“), **isti redosled** kad se nabraja, formalno „Vaš“, crtica sa razmacima (` - `) kao ritmička pauza i korist za klijenta u prvom planu. Ne kopirati rečenice sa početne — napisati nove u tom tonu. Isto važi i za labele kategorija u `vug_project_cat_labels()` (redosled: sajtovi → web aplikacije → društvene mreže).
- Comments and internal notes are in Serbian; match that when editing existing files.
- Serbian copy uses proper diacritics (č, š, ž, đ) and capital **V** for the formal "Vaš" (see the user memory note).
- Counter stats in the hero: numeric values animate via `.counter` (`data-target` + `data-suffix`); non-numeric values like `24/7` are rendered as static text, not counters.
- `.htaccess` files block direct access to `/php/` and `/lang/`; `robots.txt` disallows them too. Keep secrets and logic in those dirs.
- **Nijedna email adresa ne sme da stoji kao čist tekst u HTML izvoru** (spam harvesteri + SEO provere to prijavljuju). Koristi `vug_email_obf()` iz `php/icons.php` (HTML entity obfuskacija) za prikaz i za `mailto:`. `legal.php` piše `%EMAIL%` token u tekstovima, a `$legal_text()` ga zameni posle `htmlspecialchars()`. Ni placeholder-i u formama ne smeju biti u obliku `nesto@nesto.tld` — zato je `form_email_ph` opisni tekst.
- Editing config: `$TO_EMAIL`/`$FROM_EMAIL` are constants at the top of `php/contact.php`. SEO/meta (title, description, JSON-LD, hreflang) is built in the `<head>` of `index.php` from `$t` values and `$current_url`.
